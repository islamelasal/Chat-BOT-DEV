### المهام الأصلية (الأيام 15–21)

| المهمة | المخرَج | DoD |
|---|---|---|

## المرحلة 4 — الاحتراف (الأسابيع 5–8)

- ✅ **جمع بيانات العملاء المحتملين (Lead Capture)** — جدول leads + واجهة ودجت + صفحة لوحة + CSV (منجزة من البحث التنافسي).
- ✅ **زحف روابط الموقع للتدريب التلقائي** — POST /bots/:id/crawl + واجهة في محرر المعرفة (مثل SiteGPT).
- ✅ **تحويل بشري**: لوحة "تواصل معانا" (واتساب/اتصال/بريد) داخل الودجت + إعدادات لكل عميل + يُحصى في العدادات (status=handoff).
- **Webhooks**: إرسال كل بيانات جديدة (Lead/رسالة) لـ Zapier/Sheets/CRM.
- فوترة: باقات + فواتير استهلاك + ربط دفع (Paymob/Stripe) — FR-076.
- Live Inbox + تحويل بشري (Handoff) + إشعارات واتساب — FR-082.
- تقارير متقدمة + تصدير + تقارير عميل خارجية (روابط قراءة فقط) — FR-014.
- إصدارات ودجت + نشر تدريجي canary — FR-035.
- i18n (عربي/إنجليزي للوحة وللودجت) — FR-036.
- Cache للردود الشائعة + تحسينات تكلفة.
- تعزيز الأمان: ZAP + اختبار اختراق خارجي.
