## 2. موجات الترقية (كل موجة تحققت بمعزل)

### الموجة 1 — الحزم الأساسية
- zod `^3.24` → `^4.6.2` · vitest `^2.1` → `^5.0` · pg `^8.13` → `^8.23` · ioredis `^5.4` → `^6.0` · turbo `^2.10.12` · typescript `^5.9.3` · @types/node `^22.20.2`.
- **التحقق**: بناء الحزم الأربع + اختبارات البوابة 9/9.

### الموجة 2 — الـ API: NestJS 12 + هجرة ESM كاملة
- `@nestjs/*` 12.0.1 + CLI 12 · express 5.2.1 · helmet 8.3 · rxjs 7.8 · dotenv 17.4 · cors 2.8.
- **الهجرة لـ ESM** (`"type": "module"` + tsconfig NodeNext): كل الاستيرادات النسبية كانت جاهزة بامتداد `.js`؛ حُوِّلت 4 استدعاءات `require()` لاستيرادات ثابتة، و`__dirname` → `import.meta.dirname` (Node ≥20.11)، وسكربت البناء يستخدم `--input-type=commonjs` لنسخ الأصول.
- **التحقق**: بناء + إقلاع + healthz + تسجيل دخول + نبضات العامل داخل العملية + **إقلاع العامل المستقل** (`worker-main.js` ESM) + صفر أخطاء أنواع.

### الموجة 3 — اللوحة: Next.js 16 + React 19.3
- next 16.3.5 · react/react-dom 19.3 · lucide-react 1.45 · tailwindcss 4.3.3 · @tailwindcss/postcss 4.3.3.
- تحويل اللوحة لـ ESM (`"type": "module"`) لتفادي تعارض Turbopack (Next 16 يبني بـ Turbupack افتراضياً).
- **التحقق**: بناء 18 صفحة + كل الصفحات تستجيب 200 عبر `next start` + بروكسي `/backend` يمرر POST بشكل صحيح.

### الموجة 4 — الودجت: Vite 8
- vite 8.3 · @preact/preset-vite 2.10.6 · preact 10.29.8.
- **التحقق**: `frame.js` 28.5KB (gzip 10.6KB) + w.js وframe والأصول تُخدَم 200.

### الموجة 5 — تصفير الثغرات (pnpm overrides)
بعد الترقيات تبقى 7 ثغرات ترانزيتف بتصليحات patch رسمية — فُرِضت إجبارياً:
- `multer ^2.3.0` (ثغرة في مسار Nest الأساسي) · `fast-uri ^3.1.6` (SSRF/IDN) · `js-yaml ^4.3.2` (DoS) · `qs ^6.16.0` (DoS).
- **النتيجة**: `pnpm audit` → **No known vulnerabilities found**.

### الموجة 6 — البنية التحتية للنشر
- Dockerfiles: `node:22-alpine` → `node:24-alpine` (Active LTS) + **إصلاح خلل**: `pnpm-lock.yaml` لم يكن منسوخاً رغم `--frozen-lockfile` (كان سيفشل البناء).
- `docker-compose.yml`: إضافة `WEBHOOK_ALLOW_PRIVATE: 'false'` للإنتاج (SSRF).
- `requirements.txt`: إصلاح خطأ — كان يطالب بـ `scrapling>=3.0` بينما أحدث إصدار فعلي `0.4.15` (كان سيخرب التثبيت).

## 3. نقاط أمان مؤكدة (تفاعل المكونات)

- **متغيرات boolean البيئية**: بعد إصلاح `z.coerce.boolean()` (الجولة السابقة)، تحقّقنا أن `DEMO_MODE='false'` و`WEBHOOK_ALLOW_PRIVATE='false'` في docker-compose تُفسَّر **بشكل صحيح** — إعدادات الإنتاج سليمة فعلياً الآن.
- **SSRF**: إنشاء webhook لعناوين داخلية يُرفض عند `WEBHOOK_ALLOW_PRIVATE=false` (مُختبَر).
- **helmet** مطبق على الـ API مع استثناءات مدروسة (CSP/frame) لأن الودجت يجب أن يعمل داخل مواقع العملاء.
- **TLS**: Traefik بمدخل `websecure:443` — https مفروض في الإنتاج؛ والمعاينة نفسها تعمل عبر https.
- **الأسرار**: مفاتيح المزودين AES-256-GCM، جلسات الودجت HMAC، كلمات المرور scrypt — لا تغيير (سليمة من الجولات السابقة).

## 5. قرارات مؤجلة صراحةً (ADRs)

1. **TypeScript 7 (المجمع الأصلي)**: متاح (7.0.2) لكن منظومة Nest/Next ما زالت تعتمده تدريجياً — نبقى على 5.9.3 (آخر 5.x مستقر) ونراجع في الربع القادم.
2. **Node 24 في Docker**: مُعتمد (Active LTS)؛ بيئة الساندبوكس على Node 22 (متوافقة عبر `engines: >=22.5`) — يُنصح بفحص دخان على 24 قبل أول نشر.
3. **lucide-react 1.x**: أيقوناتنا كلها موجودة في v1 (البناء والفحص نجحا) — نراقب أي إزالة مستقبلية للأسماء.
4. **BullMQ / OTel / Grafana**: تبقى خطط توسع (موثقة في ROADMAP) — البنية الحالية (طوابير DB بادّعاء متفائل + نبضات + تنبيهات) كافية لمرحلة الإطلاق.
