## 3. القرارات المحسومة

1. **الاستضافة**: VPS واحد (~25$/شهر) عبر `docker compose up -d` — لأن العامل 24/7 والمزامنة الدورية يحتاجان عملية دائمة (PaaS Serverless غير مناسب).
2. **الودجت**: اعتماد الـ Snippet البسيط ✅ — إضافة CS-Cart جاهزة + Block HTML بديل.
3. **المفاتيح**: OpenRouter جاهز في `apps/api/.env` (يُثبَّت مشفراً — **التدوير مطلوب قبل الإنتاج لأنه ظهر في محادثة**). مفتاح CS-Cart API مطلوب من العميل لتفعيل تتبع الطلبات.

## 4. ما اكتمل في هذه الجولة (استكمال كافة الأشياء)

- ✅ **تتبع الطلبات عبر CS-Cart REST API** (`POST /w/order`): حساب بوت بـ API access + Basic Auth + خريطة حالات عربية + تحقق إيميل اختياري + رد بنبرة كنز الشوا + زر "📦 تتبع طلبك لحظياً" في الودجت
