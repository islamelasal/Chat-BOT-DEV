## 4ب. جولة 2026-08-20 — Webhooks + إحصاءات غير المجابة + إصلاحات حرجة

- ✅ **Webhooks صادرة كاملة** (ترحيل v7): نقاط وصول لكل عميل + توقيع HMAC-SHA256 + تراجع أسي حتى 5 محاولات + حماية SSRF + سجل تسليمات + اختبار فوري + إيقاف/تفعيل + صفحة `/webhooks` في اللوحة. مُختبَر E2E ضد مستقبِل محلي لكل الأحداث الستة (التوقيع تحقق فعلياً).
- ✅ **الأسئلة غير المجابة**: جدول `unanswered_questions` بتطبيع عربي + تسجيل تلقائي عند الرد الاحتياطي + قسم «الأسئلة غير المجابة» في صفحة `/usage` (حلّ/إعادة فتح).
- 🐛 **إصلاح حرج 1 — تتبع الطلبات كان مكسوراً**: `z.string().email().optional().default('')` في Zod يُطبِّق القيمة الافتراضية قبل التحقق — أي زائر يتتبع طلباً بدون كتابة بريد كان يحصل على HTTP 400. أُصلح بـ `preprocess` (أيضاً `handoffEmail`).
- 🐛 **إصلاح حرج 2 — متغيرات boolean البيئية**: `z.coerce.boolean()` يحوّل النص `'false'` إلى `true` — أي أن `DEMO_MODE=false` في الإنتاج كان سيُترك وضع الديمو مفعّلاً! أُصلح بمحول boolean آمن لكل مفاتيح الإعدادات (تحققنا باختبار `DEMO_MODE=false` و`WEBHOOK_ALLOW_PRIVATE=false`).
- ✅ **توثيق التتبع**: `docs/TRACEABILITY.md` — مصفوفة متطلبات لكل دفعة (16 متطلباً موثقاً ومتحققاً).
- ✅ **مستقبِل اختبار**: `scripts/webhook-receiver.py` (يتحقق من التوقيع — قابل لإعادة الاستخدام).
