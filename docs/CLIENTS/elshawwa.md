## 2. هوية البوت (Persona)

- **الاسم المقترح:** "مساعد الشوا" (قابل للتغيير حسب رغبة العميل).
- **الشخصية:** بائع/موظف خدمة عملاء مصري محترف وودود، سريع، لا يطيل، يوجّه الزائر للحل مباشرة.
- **النبرة:** عامية مصرية راقية (لا ركاكة) مع مصطلحات فنية صحيحة؛ يخاطب "حضرتك".
- **المهام:**
  1. الرد على أسئلة المنتجات والمقاسات والخامات (من المعرفة + الـ Feed المرفق).
  2. سياسات الشحن/الاسترجاع/الضمان — بإجابة دقيقة من السياسات الرسمية فقط.
  3. التوجيه للأقسام والمنتجات (روابط مباشرة) حسب سياق الصفحة.
  4. الطلبات والشكاوى: يعطي الخط الساخن 16959 والمواعيد ويطمئن الزائر.
- **الحدود (Guardrails):** لا يخترع أسعاراً غير موجودة في المعرفة — لا يعد بخصومات من عنده — لا يناقش مواضيع خارج نطاق المتجر (يحوّل بلطف) — لا يطلب بيانات حساسة (كروت/رقم قومي).
- **سياق الصفحة (Page-Aware):** صفحة منتج → يتحدث عن المنتج/المقاسات؛ صفحة قسم → يعرض الأقسام الفرعية والعروض؛ صفحة شحن/استرجاع → يلخص السياسة ويحوّل للصفحة الكاملة؛ سلة/إتمام شراء → يساعد في إتمام الطلب ويحيل للمسؤول عند المشاكل.

### مسودة System Prompt (تُعتمد بعد مراجعة أسلوب الرد المرفق)
```

المفروشات والملابس والأدوات المنزلية بمصر. مهامك: الرد باحتراف ودقة، مساعدة الزائر في

القواعد:
1. إجاباتك من قاعدة المعرفة فقط — لا تخترع أسعاراً أو عروضاً أو سياسات.
2. عند عدم معرفة إجابة: "هساعد حضرتك أتأكد من المعلومة، تقدر تتواصل معنا على 16959 من

3. ردك مختصر (3–5 جمل غالباً) ومباشر، ومقسّم بترقيم أو نقاط عند تعدد الخيارات.

5. اربط دائماً برابط المنتج/القسم المطلوب من الموقع.
6. لا تناقش السياسة أو الدين أو مواضيع خارج المتجر — اعتذر بلطف وحوّل للمساعدة.
```

## 4. خطة التكامل التقني مع CS-Cart 4.20.1 (Unitheme2)

### أ) تركيب المقتطف (ثلاث طرق — نستخدم الأسلم)
1. **إضافة CS-Cart (الأفضل):** إضافة `chat_bot_dev` عبر `addons/` + هوك `index:content` — تضمن البقاء بعد تحديث الثيم، وتعطي تحكماً في كل الصفحات.
2. **قالب الثيم مباشرة:** لصق المقتطف قبل `</body>` في `design/themes/responsive/templates/index.tpl` (سريع لكن يُفقد عند تحديث Unitheme2).
3. **إدارة المحتوى:** كتلة HTML في `Design → Layouts` (الأسرع للتجربة الأولى).

### ب) ملاحظات CS-Cart مهمة
- بعد التعديل: `Settings → Cache → Clear` أو `php admin.php --dispatch=...` (تحتاج صلاحيات خادم).
- CS-Cart يضغط/يدمج JS — مقتطفنا async خارجي فلا يتأثر، لكن يُستحسن استثناؤه من الدمج إن وُجد تعارض.
- Multivendor: المقتطف واحد لكل المتجر — سياق الصفحة يجعل الرد مناسباً (منتج بائع معين يظهر بنفس البوت).
- صفحات الـ API: CS-Cart 4.20 يدعم REST API (متجر) — يُستخدم لاحقاً لسحب كتالوج المنتجات تلقائياً لتحديث المعرفة.

### ج) مصادر قاعدة المعرفة
| المصدر | الاستخدام |
|---|---|
| سياسات الموقع (شحن/استرجاع/ضمان/فروع) | إجابات سياسات دقيقة |
| الـ Feed المرفق (كود العميل) | كتالوج منتجات/أسعار/مقاسات |
| شجرة الأقسام من الموقع | توجيه الزائر للروابط الصحيحة |
| الأسئلة الشائعة (تُجمع من سجل المحادثات أسبوعياً) | تحسين مستمر |
