# مصفوفة التتبع (Traceability Matrix) — دفعة Webhooks + الأسئلة غير المجابة

> وثيقة حية لكل دفعة تطوير: تُحدَّث عند بداية الدفعة، ويُؤشَّر على كل متطلب بعد التحقق.
> المنهجية: تفكيك المتطلبات → تنفيذ ذرّي متدرج → فحص end-to-end → تدقيق ذاتي سطراً بسطراً.

## دفعة 2026-08-20: Webhooks صادرة (Zapier/Sheets/CRM) + إحصاءات الأسئلة غير المجابة

### A. Webhooks الصادرة

| # | المتطلب | الحالة | التحقق |
|---|---|---|---|
| A1 | جدول `webhook_endpoints` (client_id, url, secret, events, active, last_status) | ✅ | `sqlite3` / فحص الجدول |
| A2 | جدول `webhook_deliveries` (payload, attempts, next_attempt_at, status, response_code, duration_ms) | ✅ | اختبار E2E بالاستقبال المحلي |
| A3 | أحداث: `lead.created` / `conversation.message` / `handoff.requested` / `order.tracked` / `catalog.synced` / `webhook.test` | ✅ | إطلاق كل حدث والتحقق من وصوله |
| A4 | توقيع HMAC-SHA256 (`X-CBD-Signature` + `X-CBD-Signature-Timestamp`) يتحقق منه المستلم | ✅ | Receiver يتحقق من التوقيع بنفس السر |
| A5 | إعادة المحاولة بتراجع أسي (30ث/2د/10د/1س/6س) حتى 5 محاولات ثم `dead` | ✅ | Receiver يرجّع 500 ويُراقَب الجدول |
| A6 | حماية SSRF (منع العناوين الخاصة في الإنتاج — `WEBHOOK_ALLOW_PRIVATE`) | ✅ | إنشاء endpoint لعنوان خاص يُرفض عند التعطيل |
| A7 | حد مهلة الطلب (timeout) + حد حجم الرزم + User-Agent مخصص | ✅ | فحص الكود + اختبار مهلة |
| A8 | عدم حجب مسار الودجت: الإيداع في قائمة ثم المعالجة غير متزامنة (fire-and-forget) | ✅ | قياس زمن `/w/lead` < 100ms زيادة |
| A9 | REST API كامل: قائمة/إنشاء/تعديل/حذف/اختبار/عمليات تسليم/إعادة إرسال | ✅ | curl لكل endpoint |
| A10 | صفحة لوحة `/webhooks` (RTL) + قائمة جانبية + إخفاء السر + زر اختبار + جدول تسليمات | ✅ | فحص المتصفح عبر preview |
| A11 | معالجة `webhook_deliveries` من العامل داخل العملية + العامل المستقل (ادّعاء متفائل ضد التكرار) | ✅ | فحص السجلات في الوضعين |

**حالات الخطأ المغطاة**: عنوان غير صالح / خاص · انقطاع المستقبِل (500/مهلة) · تجاوز المحاولات → `dead` · سر مفقود → توقيع فارغ؟ لا — يتطلب سراً إلزامياً · مستقبِل بطيء (timeout 8ث) · عدم وجود endpoints نشطة → skip بدون خطأ · حدث غير مشترك فيه → skip.
