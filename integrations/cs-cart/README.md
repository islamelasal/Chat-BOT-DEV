# 🛒 تركيب بوت Chat Bot Dev على CS-Cart 4.20.1 (Multivendor Ultimate + Unitheme2)

> ملف العميل المرجعي الكامل: `docs/CLIENTS/elshawwa.md`

## الطريقة 1 — إضافة CS-Cart (موصى بها ✅)

1. انسخ المجلد `addons/chat_bot_dev` إلى جذر متجرك (بجانب مجلد `addons` الموجود):
   ```
   scp -r addons/chat_bot_dev user@server:/var/www/elshawwa/addons/
   ```
2. من لوحة الإدارة: **Add-ons → Manage add-ons** → ابحث عن **Chat Bot Dev** → فعّلها.
3. اضبط رابط الودجت في إعدادات الإضافة (من لوحة Chat Bot Dev → العميل → مقتطف التضمين):
   ```
   https://widget.chatbotdev.app/w.js?id=clt_elshawwa
   ```
4. امسح الكاش: **الإدارة → إعدادات → كاش** (أو من الخادم: `rm -rf var/cache/*`).
5. اختبر على: الرئيسية، صفحة منتج، صفحة قسم، صفحة سياسة الشحن.

### لماذا هذه الطريقة؟
- لا تلمس قوالب الثيم ⇒ **تحديثات Unitheme2 لن تكسر البوت**.
- إعدادات من اللوحة بدون فتح FTP كل مرة.
- خطاف `index:scripts` القياسي قبل `</body>` يعمل مع الثيمات الافتراضية وUnitheme2.

## الطريقة 2 — كتلة HTML (الأسرع للتجربة)

1. **التصميم → التخطيطات (Design → Layouts)**.
2. أضف كتلة HTML جديدة في الموضع السفلي لكل الصفحات.
3. الصق المقتطف من لوحة Chat Bot Dev.
4. امسح الكاش واختبر.

## الطريقة 3 — قالب الثيم مباشرة (غير مفضلة)

أضف قبل `</body>` في `design/themes/responsive/templates/index.tpl`:
```html
<script src="https://widget.chatbotdev.app/w.js?id=clt_elshawwa" async defer></script>
```
⚠️ يُفقد هذا التعديل عند تحديث الثيم — استخدم الطريقة 1.

## ملاحظات تشغيل مهمة

| الموضوع | الملاحظة |
|---|---|
| **CS-Cart يدمج/يضغط JS** | مقتطفنا `async` خارجي فلا يتأثر بالدمج — إن ظهر تعارض نادر، استثنِ `widget.chatbotdev.app` من الدمج في إعدادات الثيم. |
| **Multivendor** | المقتطف واحد لكل المتجر — سياق الصفحة يجعل الرد مناسباً لكل صفحة منتج. |
| **SSL/Cloudflare** | الموقع خلف Cloudflare مع حماية hotlink — الودجت من دوميننا الخاص فلا يتأثر. |
| **إزالة الإضافة** | Add-ons → عطّل → احذف المجلد — جدول `csp_chat_bot_dev_events` يُحذف تلقائياً (queries/uninstall). |
| **تتبع اختياري** | جدول `?:chat_bot_dev_events` جاهز لتسجيل أحداث الصفحات لاحقاً (لا يُستخدم حالياً). |

## استكشاف الأخطاء

- **البوت لا يظهر؟** تأكد: الإضافة مفعّلة + الكاش اُمسح + الرابط يبدأ بـ `https://` + جرّب وضع التصفح الخفي.
- **يظهر بشكل مكسور؟** افتح متصفح → DevTools → Console — الودجت معزول (iframe) فلا يتعارض مع CSS الثيم؛ راسلنا بلقطة الشاشة إن استمر.
- **رسالة "النطاق غير مسموح"؟** أضف دومين المتجر (مع وبدون www) في لوحة Chat Bot Dev → العميل → النطاقات المسموحة.
