# Project Agent — وكيل المشروع داخل Chrome

إضافة Chrome بسيطة واحترافية تعمل كـ **Side Panel** بجانب الصفحة الحالية. تقرأ عنوان الصفحة ومحتواها والنص المحدد، ثم ترسل السياق مع المحادثة إلى وكيل مشروع مبني على **Google Gemini API** ذي الخطة المجانية. بذلك يمكنك متابعة مشروعك مع الذكاء الاصطناعي من أي صفحة بدلاً من نسخ المحتوى يدوياً.

> مفتاح API لا يأتي مضمّناً في المشروع. يضعه المستخدم بنفسه من الإعدادات، ويُحفظ محلياً في `chrome.storage.local` ولا يُرفع إلى هذا المستودع.

## المزايا

- محادثة مستمرة لكل مشروع، مع حفظ الرسائل محلياً.
- سياق الصفحة الحالية: العنوان، الوصف، العناوين، المحتوى الأساسي، والنص المحدد.
- شخصية وكيل احترافية باللغة العربية، مناسبة للتخطيط والبرمجة والمراجعة والمحتوى.
- أربعة أنماط للوكيل: مدير مشروع، مطوّر، مراجع، ومخطط محتوى.
- زر تحديث السياق، وإمكانية إيقاف التوليد، نسخ الرد، وتصدير المحادثة إلى Markdown.
- قائمة سياق: حدّد أي نص في الصفحة واضغط **اسأل وكيل المشروع عن النص المحدد**.
- لا توجد حزمة build أو تبعيات خارجية؛ يمكن تحميل المجلد مباشرة كإضافة غير معبأة.

## التشغيل

1. افتح [Google AI Studio](https://aistudio.google.com/app/apikey) وأنشئ مفتاح Gemini API ضمن الخطة المتاحة لحسابك.
2. افتح `chrome://extensions` في Chrome.
3. فعّل **Developer mode**.
4. اضغط **Load unpacked** واختر مجلد هذا المشروع كاملاً.
5. اضغط أيقونة الإضافة لفتح Side Panel.
6. افتح الإعدادات داخل الإضافة، ألصق المفتاح، اختر النموذج، ثم اضغط **حفظ الإعدادات**.
7. أنشئ مشروعاً واكتب فكرته المختصرة، ثم ابدأ المحادثة. سيستمر سجل ذلك المشروع عند الرجوع إليه لاحقاً.

النموذج الافتراضي هو `gemini-2.5-flash`، ويمكن تغييره من الإعدادات إذا كان حسابك يتيح نموذجاً آخر. حدود الخطة المجانية وأسماء النماذج قد تتغير من Google؛ لا يتم تجاوز أي حد أو التحايل عليه من داخل الإضافة.

## بنية ملفات الوكيل

- `src/agents/professional-project-agent.js`: ينسّق سجل المحادثة وسياق المشروع ويرسل الطلب.
- `src/agents/prompts.js`: قواعد الشخصية الاحترافية وأوضاع الوكيل.
- `src/agents/context-builder.js`: يبني مرجع الصفحة مع حماية من تعليمات الصفحة غير الموثوقة.
- `src/lib/gemini-client.js`: عميل Gemini API مع معالجة الأخطاء والإيقاف.
- `src/lib/storage.js`: حفظ المشاريع والإعدادات محلياً.
- `sidepanel.html`, `sidepanel.css`, `sidepanel.js`: واجهة المحادثة.
- `content.js`: استخراج سياق الصفحة والنص المحدد.
- `background.js`: Side Panel وقائمة سياق الاختيار.

## الخصوصية والصلاحيات

عند تفعيل **إدراج سياق الصفحة تلقائياً**، يتم إرسال النص المستخرج من الصفحة مع طلب المحادثة إلى Google Gemini. عطّل هذا الخيار للحديث دون محتوى الصفحة. الإضافة لا تجمع تحليلات ولا تحتوي على مفتاح جاهز، لكن صلاحية قراءة الصفحات (`<all_urls>`) مطلوبة كي تعمل مع المواقع المختلفة. لا تستخدمها مع صفحات تحتوي على أسرار إلا بعد مراجعة السياق والإعدادات.
