# Project Agent — وكيل المشروع الاحترافي داخل Chrome

إضافة Chrome حديثة تعمل كـ **Side Panel** بجانب الصفحة الحالية. صُممت لتتحدث معك باحترافية، تفهم هدف المشروع، تقرأ سياق الصفحة والمصادر المفتوحة، وتكمل معك من حيث توقفت بدلاً من تقديم إجابات عامة منفصلة.

> تم تحديث المشروع مع الاستفادة من أحدث تقنيات Gemini المتاحة وممارسات بناء الوكلاء الحديثة في Chrome Manifest V3: التفكير المتدرج، الرد المتدفق، البحث المباشر، قراءة الروابط، المراجع القابلة للفتح، وتحسين التعامل مع سياق المشاريع.

## ما الجديد في الإصدار 1.2.0

- **ذكاء أعلى في طريقة الرد:** الوكيل يحدد نوع الطلب أولاً، ثم يقدم خلاصة وقراراً وخطوات تنفيذ وتحقيقاً للنتيجة والخطوة التالية.
- **تفكير متدرج قابل للتحكم:** سريع، متوازن، أو عميق للبرمجة والمشروعات المعقدة.
- **ردود متدفقة عبر SSE:** يبدأ الرد بالظهور فور وصول أول جزء بدلاً من انتظار نهاية الطلب.
- **بحث مباشر في Google:** مناسب للأخبار والإصدارات والأسعار والمعلومات المتغيرة، مع إظهار مراجع البحث.
- **قراءة الروابط بعمق:** يمرر الروابط العامة إلى أداة URL Context للحصول على معلومات أحدث من محتوى الصفحة المختصر.
- **تحقق حسابي آمن اختياري:** يمكن لـ Gemini تشغيل Python داخل بيئته السحابية للتحقق من الحسابات؛ الإضافة لا تشغّل كوداً على جهازك.
- **ربط صفحات متعددة:** زر «＋ صفحات» يجمع صفحات الويب المفتوحة في النافذة ويجعلها مصادر إضافية للمحادثة.
- **مراجع شفافة:** تظهر مصادر البحث والروابط أسفل الرد، ويمكن فتحها أو تصديرها مع المحادثة.
- **توافق ذكي مع الخطة المجانية:** أدوات البحث والروابط اختيارية وتبدأ متوقفة لحماية الحصة. وإذا رفضت حصة حسابك إحدى الأدوات بعد تفعيلها، تعيد الإضافة الطلب بدون الأداة مع وسم «أدوات احتياطية» بدلاً من انهيار المحادثة.
- **اختيار نماذج حديثة:** قائمة اختيار ثابتة للنماذج الحديثة مثل `gemini-3.7-flash`، مع نموذج احتياطي `gemini-3.5-flash-lite` وخيارات Flash-Lite للحصة والسرعة.
- **استمرارية المشروع:** كل مشروع يحتفظ بسجل مستقل، وملخص المشروع، وقراراته السابقة.
- **ربط محادثة AI موجودة:** يكتشف ChatGPT وGoogle Gemini وClaude وPerplexity في التبويب النشط، ويستورد سجل المحادثة إلى مشروعك.
- **Autopilot مضبوط وآمن:** يرسل الوكيل الخطوة التالية إلى محادثة AI المفتوحة، ينتظر الرد، يراجع التقدم، ويكرر حتى `done` أو `blocked` أو الحد الآمن للدورات. التشغيل يحتاج ضغط المستخدم ويمكن إيقافه في أي لحظة؛ لا توجد حلقة لا نهائية أو تنفيذ صامت.
- **أمان أفضل:** مفتاح API يرسل في header مخصص ولا يوضع في عنوان URL، ولا توجد مفاتيح سرية داخل المستودع.

## الخدمات المتاحة للوكيل

- تحليل الصفحة الحالية ومحتواها الأساسي.
- استخراج العناوين، الروابط المهمة، مقاطع الكود، نوع الصفحة، اللغة، والنص المحدد.
- تخطيط المشاريع وتحويل الفكرة إلى milestones وخطوات قابلة للتنفيذ.
- مراجعة الكود والبنية واكتشاف المخاطر والحالات الطرفية.
- البحث عن أحدث المعلومات مع فصل الحقائق المتحقق منها عن الاقتراحات.
- مقارنة أكثر من مصدر أو صفحة مفتوحة.
- كتابة نصوص احترافية، مواصفات، رسائل، توثيق، وملفات جاهزة.
- إيقاف الرد مع الاحتفاظ بالجزء الذي تم توليده.
- نسخ الرد أو تصديره بصيغة Markdown مع روابط المصادر.

## التشغيل

1. افتح [Google AI Studio](https://aistudio.google.com/app/apikey) وأنشئ مفتاح Gemini API ضمن الخطة المتاحة لحسابك.
2. افتح `chrome://extensions` في Chrome 116 أو أحدث.
3. فعّل **Developer mode**.
4. اضغط **Load unpacked** واختر مجلد هذا المشروع كاملاً.
5. اضغط أيقونة الإضافة لفتح Side Panel.
6. افتح الإعدادات، ألصق المفتاح، اختر النموذج ومستوى التفكير، ثم اضغط **حفظ الإعدادات**.
7. أنشئ مشروعاً واكتب فكرته المختصرة، ثم ابدأ المحادثة.
8. استخدم «＋ صفحات» إذا أردت ربط أكثر من صفحة مفتوحة بالمشروع.

### النماذج المقترحة

- `gemini-3.7-flash`: أحدث خيار Flash متاح في الإعدادات للمهام الاحترافية.
- `gemini-3.5-flash`: نموذج احتياطي متوازن إذا لم يكن النموذج الأحدث متاحاً لمفتاحك.
- `gemini-3.5-flash-lite`: أسرع وأخف للاستخدام المتكرر.
- `gemini-2.5-flash-lite`: خيار اقتصادي للتوافق والحصة.

أسماء النماذج وحدود الخطة المجانية وتوفر الأدوات قد تتغير من Google. الإضافة لا تتجاوز حدود الاستخدام ولا تضمن أن كل نموذج مجاني لكل حساب؛ اختر النموذج المتاح لمفتاحك من الإعدادات.

### استكمال محادثة AI مفتوحة تلقائياً

1. افتح محادثة مشروعك في ChatGPT أو Gemini أو Claude أو Perplexity.
2. افتح Side Panel واضغط **تحديث الحالة** في بطاقة «محادثة AI المفتوحة».
3. اضغط **استيراد المحادثة** لحفظ سجلها داخل المشروع الحالي.
4. اكتب هدف الاستكمال، أو اتركه فارغاً لاستخدام ملخص المشروع.
5. اختر الحد الآمن للدورات ثم اضغط **بدء الاستكمال التلقائي**.

في كل دورة يقرأ المنسق آخر رد، يصيغ خطوة تنفيذية، يرسلها إلى محرر AI المفتوح، ثم ينتظر الرد قبل الدورة التالية. يتوقف عند اكتمال المشروع أو وجود عائق أو بلوغ الحد الآمن. لا يمكن للإضافة أن تدّعي اكتمال مشروع لم يتم التحقق منه، ولا تتجاوز صلاحيات موقع AI أو تطبق تغييرات محلية دون تدخل المستخدم.

### عند ظهور رسالة Rate Limit

هذا يعني أن مفتاح Google وصل إلى حد الطلبات في الدقيقة أو الحصة اليومية، وليس أن الإضافة لا تحفظ النموذج. انتظر مدة التهدئة الظاهرة في أعلى اللوحة، ثم اختر `gemini-2.5-flash-lite` أو `gemini-3.5-flash-lite` وعطّل البحث المباشر وقراءة الروابط إذا كنت تستخدم خطة مجانية. اختيار النموذج أصبح قائمة واضحة ويتم حفظه في الإعدادات.

## طريقة الرد الاحترافية

تمت إعادة بناء تعليمات الوكيل بحيث يتعامل مع الرسالة وفق هذا التسلسل:

1. يحدد هل الطلب سؤال مباشر، تخطيط، بحث، كتابة، مراجعة، أو تطوير.
2. يراجع ملخص المشروع وسجل المحادثة وسياق الصفحة والمصادر الإضافية.
3. يتحقق من المعلومات المتغيرة باستخدام البحث أو قراءة الروابط عند تفعيلها.
4. يقدم خلاصة واضحة، ثم تفاصيل عملية، ثم كوداً أو خطوات عند الحاجة.
5. يذكر الافتراضات والمخاطر وما يحتاج إلى اختبار.
6. ينهي الرد بخطوة تالية قابلة للتنفيذ، ويعرض المصادر التي استخدمها.

الوكيل لا يعرض chain-of-thought أو تفكيراً داخلياً سرياً؛ يعرض فقط ملخصاً منطقياً وقرارات يمكن مراجعتها.

## بنية المشروع

- `manifest.json`: Chrome Manifest V3 وSide Panel والصلاحيات.
- `background.js`: تهيئة Side Panel وقائمة السياق للنص المحدد.
- `content.js`: استخراج سياق الصفحة والروابط ومقاطع الكود والنص المحدد.
- `sidepanel.html`, `sidepanel.css`, `sidepanel.js`: الواجهة والمحادثة وإدارة المشاريع.
- `src/agents/professional-project-agent.js`: orchestration لسجل المحادثة والمصادر والرد المتدفق.
- `src/agents/autopilot-coordinator.js`: منسق آمن يقرر الخطوة التالية وحالات `continue`, `done`, و`blocked`.
- `src/agents/prompts.js`: الشخصية المهنية وسياسة التفكير والرد.
- `src/agents/context-builder.js`: بناء سياق آمن للصفحة والمصادر الإضافية.
- `src/lib/gemini-client.js`: عميل Gemini الحديث، SSE، التفكير، الأدوات، المصادر، وإعادة المحاولة بالنموذج الاحتياطي.
- `src/lib/storage.js`: حفظ الإعدادات والمشاريع والرسائل محلياً.
- `src/lib/format.js`: Markdown آمن، الروابط، المصادر، والتصدير.

## الخصوصية والصلاحيات

- مفتاح API والمشاريع محفوظة محلياً في `chrome.storage.local`، ولا يتم رفعها إلى هذا المستودع.
- عند تفعيل **إدراج سياق الصفحة** يتم إرسال النص المستخرج مع الطلب إلى Google Gemini.
- عند الضغط على **استيراد المحادثة** أو تشغيل Autopilot، يتم إرسال سجل محادثة AI المفتوحة إلى منسق Gemini لتحديد الخطوة التالية؛ لا يتم ذلك تلقائياً دون ضغط المستخدم.
- عند تفعيل **البحث المباشر** أو **قراءة الروابط** قد تستخدم Google أدواتها للوصول إلى معلومات عامة من الويب، وتظهر المراجع في الرد.
- **تحقق حسابي آمن** يعمل في بيئة Google السحابية ولا يصل إلى ملفات جهازك أو ينفذ أوامر محلية.
- صلاحية `<all_urls>` مطلوبة حتى يعمل الوكيل مع المواقع المختلفة. لا تستخدمه مع صفحات الأسرار أو الحسابات الحساسة إلا بعد مراجعة الإعدادات.
- لا توجد تحليلات أو مكتبات خارجية أو API key جاهز داخل المشروع.
