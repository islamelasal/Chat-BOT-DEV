## 🎯 الحالة الحالية

- ✅ البحث الكامل واعتماد القرارات التقنية والخطة
- ⏳ المرحلة 0 (التأسيس) → المرحلة 1 (النواة) → المرحلة 3 (إطلاق الشوا)
- ⏳ مدخلات معلّقة: ملفات البراند المرفقة لعميل الشوا (لوجو + ألوان + كود الـ Feed + نماذج أسلوب الرد)

## 🧰 المكدس

TypeScript بالكامل · pnpm Monorepo (Turborepo) · Next.js 15 (لوحة تحكم RTL) · NestJS (API + Worker 24/7) · PostgreSQL + Redis (BullMQ) · Preact Widget معزول (Shadow DOM + sandbox iframe) · Prisma · Docker/Traefik · Sentry/Grafana

## 🗂️ هيكل المستودع

```
apps/
  dashboard/   لوحة التحكم (Next.js)
  api/         خدمة API + البوابة (NestJS)
  worker/      العمال والجدولة 24/7 (NestJS + BullMQ)
  widget/      ودجت موقع العميل (Preact + Vite)
packages/
  shared/      الأنواع ومخططات zod المشتركة
  ai-gateway/  المحوّلات + الراوتر + دوائر الكسر + العدادات
  ui/          مكونات الواجهة المشتركة
infra/         Docker Compose + Traefik + نسخ احتياطي
docs/          الوثائق الكاملة
```
